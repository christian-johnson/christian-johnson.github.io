Generating example multimember district maps

This app generates a set of contiguous, county-bounded districts such that each district has roughly the same representation in a legislative body (population estimates are from US Census data, current as of July 1, 2021).

Note that there are many potential solutions to finding a suitable set of districts; this app generates them in a random way, so you will get different results each time you run it. In some states, it may be trickier to find a solution than in others, depending on the connectivity of the state's counties. If the algorithm fails to find a solution, it will automatically try again (up to 10 times) with a different initial starting guess.

The tolerance parameter determines how similar the population per representative of each district needs to be in order for a solution to be valid. Higher tolerance will converge faster, and if you set the tolerance too low, it may not converge at all.

The estimated partisan breakdown is calculated by aggregating the results of the 2020 presidential election in each district, and allocating legislature seats based on the proportion of total votes. Because the 2020 election was three years ago, and because local races will invariably be influenced by factors other than national partisanship, the partisan breakdowns should be viewed as a rough estimate for illustration purposes - not a firm prediction of precisely what would happen under these maps.
